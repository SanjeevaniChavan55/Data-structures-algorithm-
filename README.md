# Data-structures-algorithm-
This project demonstrates the practical application of Data Structures and Algorithms using Python.
It focuses on two important algorithmic strategies: Divide and Conquer and Greedy Algorithm.
1. E-commerce Product Sorting – Divide and Conquer
The E-commerce Product Sorting application sorts products according to their prices. It uses the Merge Sort algorithm, which follows the Divide and Conquer approach.
The product list is divided into smaller parts, each part is sorted recursively, and the sorted parts are finally merged to produce the complete sorted list.
Algorithm: Merge Sort
Strategy: Divide and Conquer
Time Complexity: O(n log n)
2. Google Calendar Scheduling – Greedy Algorithm
The Google Calendar Scheduling application selects the maximum number of non-overlapping events from a given list of calendar activities.
It uses the Activity Selection algorithm, a Greedy approach in which events are sorted according to their finishing time. The algorithm then selects compatible events that finish earliest.
Algorithm: Activity Selection
Strategy: Greedy Algorithm
Time Complexity: O(n log n)
